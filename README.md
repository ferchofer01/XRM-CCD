# XRM-CCD

Aplicación de consulta y reporte de vulnerabilidades.

## Requisitos

- Python 3.9 o superior.

## Ejecución

```bash
python app/vulnerability_consultant.py
```

## Funcionalidades

- Listar las vulnerabilidades disponibles en el repositorio local.
- Buscar vulnerabilidades por ID o palabras clave.
- Mostrar la descripción y pasos de remediación de cada vulnerabilidad.
- Agregar vulnerabilidades a un reporte y generar un archivo Markdown con los resultados.

Los reportes se guardan en la carpeta `reports/` dentro del proyecto.
